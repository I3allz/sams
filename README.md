# SAMS – School Activity Management System

เว็บระบบจัดการและเช็คกิจกรรมนักเรียน ตามรายงานโครงงานฐานข้อมูล (10 ตาราง 3NF)
เทคโนโลยี: Python + Flask + SQLite (ไม่ต้องติดตั้งฐานข้อมูลเพิ่ม)

## วิธีรันบน VS Code
1. เปิดโฟลเดอร์ `SAMS` ใน VS Code (File → Open Folder)
2. เปิด Terminal (Ctrl + `) แล้วรัน
   ```
   pip install -r requirements.txt
   python app.py
   ```
   (หรือกด F5 เลือก "Run SAMS (Flask)")
3. เปิดเบราว์เซอร์ที่ http://127.0.0.1:5000

ครั้งแรกระบบสร้างไฟล์ `sams.db` พร้อมข้อมูลตัวอย่างให้เอง
ถ้าต้องการรีเซ็ตข้อมูล ให้ลบไฟล์ `sams.db` แล้วรันใหม่

## ฟังก์ชันตามโจทย์
- **นักเรียน**: ลงทะเบียน/ยกเลิก ตรวจสอบสถานะ ดูประวัติย้อนหลัง และชั่วโมง/คะแนนสะสม
- **ครู**: เพิ่ม/แก้ไข/ลบกิจกรรม กำหนดครูผู้ดูแลและหน้าที่ ดูรายชื่อ เช็คชื่อ ให้คะแนน (ครูจัดการได้เฉพาะกิจกรรมที่ตนเป็นผู้ดูแล)
- **ผู้ดูแลระบบ**: จัดการประเภทกิจกรรม ปีการศึกษา ครู นักเรียน และบัญชี/สิทธิ์ผู้ใช้
- **สะสมชั่วโมงอัตโนมัติ**: เมื่อเช็คชื่อเป็น มา/สาย แล้วเว้นช่องชั่วโมงว่าง ระบบให้ชั่วโมงเท่ากับชั่วโมงของกิจกรรมนั้น
- **Real-time**: แดชบอร์ดดึงข้อมูลใหม่ทุก 5 วินาที (ตัวเลขสถิติ + รายการเช็คชื่อล่าสุด)
- **รายงาน**: สรุปกิจกรรม/สถิติการเข้าร่วม, คะแนนและชั่วโมงสะสมของนักเรียน (กรองตามชั้น, พิมพ์ได้)
- **ER-Diagram**: เมนู "ER" (ใช้ mermaid ต้องมีอินเทอร์เน็ต)

## โครงสร้างไฟล์
```
SAMS/
├─ app.py          เซิร์ฟเวอร์ + route ทั้งหมด + ข้อมูลตัวอย่าง
├─ schema.sql      CREATE TABLE 10 ตาราง (ตรงกับหัวข้อ 5 ของรายงาน)
├─ templates/      หน้าเว็บ (Jinja2)
├─ static/style.css
└─ sams.db         สร้างอัตโนมัติเมื่อรันครั้งแรก
```
